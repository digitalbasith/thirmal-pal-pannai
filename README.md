# Thirumal Paal Pannai — Client V5

Responsive React + TypeScript + Vite + Supabase store management app.

## Included
- Dashboard and quick actions
- Multi-product billing
- Loose milk / pocket / litre / cup / cone / bottle / piece units
- Products CRUD
- Product Excel import + template download
- Separate Categories management
- Separate Clients management
- Morning stock
- Sales history
- Reports with Today / 7 Days / 30 Days / 3 Months / Custom date filters
- Excel report export
- Admin / employee access and permissions
- Shop logo / name / theme settings

## Run
```bash
npm install
npm run dev
```

Open the Vite URL, usually http://localhost:5173.
